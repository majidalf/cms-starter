Harianja & Putra CMS-Starter Architecture

Visualisasi alur kerja multi-agent di VPS Ubuntu (Hermes + OpenCode + Pencil.dev MCP)

1. Hermes Agent (Orchestrator)

  • Interface utama berbasis Telegram (chat interaktif).
  • Menggunakan model Gemini 3.5 Flash Lite.
  • Menangkap instruksi user, memanggil tool, dan mengelola orkestrasi task.

2. OpenCode / Muse-Spark (Executor)

  • Server background di port 4096 (`opencode serve`).
  • Model gratis kontributor (`muse-spark-1.3-contributor-free`).
  • Fokus menulis kode Next.js 16, Tailwind 4, dan komponen UI.

3. Pencil.dev MCP (Design Sync)

  • Terhubung lewat CLI (`pen`) dan file `Design.pen`.
  • Membaca token warna, tipografi, dan hierarki *frame* secara presisi.
  • Menjamin hasil koding identik dengan rancangan desainer.

Alur Kerja (Workflow)

  • 1. Request: User mengirim instruksi redesign atau fitur lewat Telegram.
  • 2. Planning & Sync: Hermes memparsing konteks, memeriksa file `Design.pen` via MCP/parser.
  • 3. Execution: OpenCode mengimplementasikan kode React/Next.js sesuai token desain.
  • 4. Verification & Tunnel: Build diverifikasi (`next build`), lalu diekspos secara publik lewat Cloudflare Tunnel untuk dicek langsung oleh user.
